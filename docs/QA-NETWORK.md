# 邀请联机与结算验收

日期：2026-10-24。对应 #21、#22；本轮不代表 #3 真实家庭/手机验收已完成。

## 复跑

```sh
go test -race ./...
npm --prefix web run build
QA_BASE_URL=http://127.0.0.1:8080 npm --prefix web run test:network:browser
```

脚本使用已安装的实际 Chrome，分别创建独立浏览器上下文和 Cookie。棋局只通过正式随机投掷与合法走法 API 推进；没有固定骰子、注入棋盘或测试后门。语音采集与自动播报关闭，断网由 Chrome 离线模式触发。

## 本地实测

- 两人各自打开邀请、填写昵称、准备；缺席/未准备时房主不能开始。房主开始后两端更新。
- 未入座仅持房间 ID 不能访问；客人尝试开始/暂停等房主操作被拒绝，非当前玩家提交投掷被拒绝。
- 同一投掷请求重发，骰子与统计只记一次；两端实际显示 3D 点数弹窗。
- 关闭客人页面显示离线且保留席位；同 Cookie 重新打开 `/play` 回原席位和原棋局。
- 浏览器离线后锁定操作；联网并收到新的权威快照后恢复。服务端另有 15 秒心跳与 5 秒超时。
- 真实随机对局到自然获胜，两端完成骰子/飞行/撒花后显示相同结算。刷新统计保持，房主同配置再玩保留房间和席位，客人需重新准备。
- 准备区退出释放席位；原会话可回首页创建自己的游戏。
- 四个独立上下文：长航线、完整模式、全员准备、房主结束使四端返回首页。
- 三个独立上下文：环形棋盘、无道具、全员准备与开局。
- 390px 视口检查房主和客人界面，独立设备身份无混淆；桌面视口不是实体手机验证。

Go race 测试另覆盖邀请错误/满员、原 Cookie 回已开局房间、客人越权、命令重放绑定 actor、旧语音连接不能清除下一位的授权、旧席位不能通过语音操作下一位、创建新房间不销毁旧共享房间、同配置再玩去重与重置。

统计测试覆盖超过 24 条 feed 后计数保留、教练克隆不污染统计、非法动作不计数、起飞/抵达/用卡、炸弹送回与护盾抵消区分、幸运双骰只记一次投掷。

## 边界

免注册凭据绑定原浏览器；清理 Cookie 或换设备不能找回同一席位。开局后不自动替补或托管，房主不转让，暂不支持联网 AI 席位。服务器仍为单进程内存，重启/部署后游戏失效，未完成持久化存档。

本轮联机脚本无麦克风；语音工具身份隔离使用受控单测，真实 Lingxi 的合成 WAV 回归另记入 QA-VOICE。没有声称完成多位真人同时开麦、回声/噪声、真实手机或亲子全局体验。


## 真实平台语音与发布版本

应用提交：服务端 [3f99fb8](https://github.com/zkevindev/flytogether/commit/3f99fb8)、界面 [b2f19f6](https://github.com/zkevindev/flytogether/commit/b2f19f6)、语音隔离/合并 [293d3b2](https://github.com/zkevindev/flytogether/commit/293d3b2)，均直接 main。

公网真实 Lingxi 联机语音：两个独立 Cookie 浏览器，房主用合成 WAV 说“帮我使用幸运骰”，Go 实际随机 4、2，最大 4，统计 rolls=1，客人收到相同真实点数弹窗；客人在房主回合尝试连接对讲返回 403 / NOT_YOUR_TURN。没有注入语音识别结果或上游事件，没有代表真人多人声学试验。

回归同时发现平台偶发复述旧开场白，因此在保留本轮 conversation 上下文之外，每轮提交完整 session.update 刷新本轮指令。实际单人 lucky 回归为 4、4 取 4，真实播报一致；教练六句比较/回看/确认/否定和重连也通过，前四句不写棋局。受控上游单测验证相同文案四个同时 TTS 请求只合成一次并共享音频，真实声学生效范围见 QA-VOICE。

发布检查确认服务 active、运行二进制与 release 一致、公开页面两份静态资源 SHA-256 与验证构建一致，语音配置存在，凭据文件权限 600。实际部署配置仍位于仓库之外。

可复跑额外的真实平台联机语音（需要可用服务端配置，音频路径只在本机传入）：

```sh
QA_BASE_URL=http://127.0.0.1:8080 \
QA_AUDIO_FILE=/本机合成WAV文件路径 \
npm --prefix web run test:network:voice
```
