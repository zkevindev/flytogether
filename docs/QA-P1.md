| 能力 | 当前行为 |
| --- | --- |
| 陪玩风格 | 温暖、耐心教练、简洁主持；教练适时补规则提示，简洁减少可选道具菜单 |

只问才答不会关闭已开启的麦克风，仍可掷骰、查询和请求建议。关麦与总静音在声音设置中独立控制。棋盘规则由 Go 决定，偏好不能改变随机骰子、合法动作、库存或其他席位权限。

## 真实灵矽

真实Chrome合成WAV → AudioWorklet → Go → Lingxi，教练＋只问才答模式六句：轮到谁、使用起飞卡、掷骰、让小熊号起飞、轮到谁、不要掷骰。

首次检查发现模型在操作实际完成后仍偶发错讲起飞卡条件、使用外部昵称，不能仅凭状态变更宣布语音验收通过。修复后轮次查询由Go解析，动作播报改用已提交事件生成的待读文案，明确任意点数与起飞位；模型提供语音，不重新解释这些事实。简洁模式进一步去掉可选菜单，仍保留实际结果。

修正后的公网样本：随机3点，版本1→2→3→4，飞机进度0；真实回复包含“任意点数”“起飞位”与正确昵称小朋友/爸爸，查询和否定不写入，重连不改变版本，主动host_cue为0。最终转写到首段PCM的6个样本为838、792、1160、851、851、898ms；这是有限样本和链路区间，不是声学端到端P95。

输出式TTS实际返回：教练文案包含亲子五点/六点规则，325144字节PCM；简洁轮次90088字节PCM。真实Chrome播放PCM成功，quiet接口返回204，麦克风请求0、棋局完全不变。

这些是本轮合成输入和真实上游样本，不宣称所有口音与生成回复都无误差。
