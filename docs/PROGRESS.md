## 设计决策

| 日期 | 决策 | 原因 |
| --- | --- | --- |
| 2026-10-23 | 项目名为一起飞 FlyTogether | 强调家庭共同参与和飞行棋主题 |
| 2026-10-23 | Go 是棋局和合法动作的唯一权威 | 语音、点击、AI 共用规则服务 |
| 2026-10-23 | 网页通过 Go 网关使用灵矽 Realtime | API Key 留在服务端；浏览器支持持续对话和打断 |
| 2026-10-23 | Realtime function call 映射为项目自己的游戏工具 | 规则、随机骰子和动作授权都由 Go 掌握 |
| 2026-10-23 | 默认同屏家庭游戏、最多一个 AI、快速模式优先 | 控制三天内的实现范围 |
| 2026-10-23 | P0 使用内存状态，暂不引入数据库 | 优先完成玩法与真实语音联调 |
| 2026-10-23 | 棋盘提供经典十字、长航线和环形选择 | 兼顾熟悉玩法、较长路线和原视觉方案 |
| 2026-10-23 | PR 按功能切片并回链 Issue | 让项目过程可跟踪、每步便于审阅 |
| 2026-10-23 | 部署配置不进入公开仓库 | 避免公开基础设施地址和凭据 |
