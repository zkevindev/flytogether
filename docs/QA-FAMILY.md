# 家庭飞行员与跨局战绩验收（#29）

日期：2026-10-24。服务端 `e9f59cc`，页面与回归 `1887b61`，直接main，未创建其他分支或PR。关联 [#29](https://github.com/zkevindev/flytogether/issues/29)、[#17](https://github.com/zkevindev/flytogether/issues/17)。

## 实际交付

- 首页“家庭飞行员与战绩”，档案/历史两个页签，支持方向键、Home/End切换。最多12份昵称和六种内置头像，可编辑或确认删除。
- 同屏各席选自己的家庭档案，联网房主和客人各选本浏览器资料；手填昵称仍支持。棋盘与结果显示当局头像，颜色仍对应席位。
- 资料以Cookie隔离；访问时续期一年，无账号或跨浏览器找回。房间闲置保留期仍默认7天；Cookie丢失不代表服务端资料自动擦除。
- Go 在最终动作的同一SQLite事务保存非演示自然胜负，五项累计数据来自实际规则动作，按浏览器+gameID去重。战绩写入失败时最后一步也不生效，不展示未保存的冠军。
- 最近50局和总局数；档案的参与/获胜统计也只聚合这50局。不把不同规则混排，不虚构胜率或终身排行。显示每局规则、棋盘、同屏/联网、机器人与道具配置。
- 改名不修改当前棋局和旧记录，新建游戏使用当前档案；同配置再玩保持原配置。删除档案保留旧快照；删除存档不删除独立历史。清空历史只清当前浏览器，保留最小游戏去重收据，旧房间再保存不会恢复已清空数据。

## 复跑

```sh
npm --prefix web ci
npm --prefix web run build
go build -o /tmp/flytogether-qa-server ./cmd/server
QA_FAMILY_SERVER=/tmp/flytogether-qa-server npm --prefix web run test:family:browser
```

脚本为自身进程创建临时SQLite，默认监听62531（可用`QA_FAMILY_PORT`调整），只重启自己启动的进程。访问既有实例改用`QA_BASE_URL`，默认不会重启外部服务。确需授权重启时可设`QA_FAMILY_RESTART_PYTHON`和`QA_FAMILY_RESTART_SCRIPT`指向仓库外的受控脚本；该模式确实操作目标服务，不能与同目标的发布校验并行。

测试会用独立Cookie创建示例资料和真实对局。结果JSON保存在`web/test-results/family/`或`QA_OUTPUT_DIR`，不写入真实部署地址、Cookie或密钥。
