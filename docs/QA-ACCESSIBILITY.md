# 轻量棋盘、减少动画与键盘验收（#31）

日期：2026-10-24。应用 `9b6cb8d`（首批功能 `b7dc761`），直接main分批交付，无其他分支或PR。关联 [#31](https://github.com/zkevindev/flytogether/issues/31)、[#17](https://github.com/zkevindev/flytogether/issues/17)。

## 已交付

首页与对局页右上角“显示与操作设置”：

- 自动立体或轻量平面。轻量通过独立SVG模块加载，不创建WebGL画布，也不下载立体棋盘模块；立体模块加载失败时可直接转轻量。切换保留Go当前棋局、骰子、道具与版本。
- 跟随系统或减少动画。默认跟随系统，系统偏好变化实时生效；显式减少动画关闭骰子旋转、飞行过渡、落点/合法棋子脉动、撒花粒子与装饰动画，仍保留真实点数、落点和抵达文字。静态骰子显示真实结果：键盘游玩时点“继续飞行”或Enter确认，点击和语音自动继续；声音偏好独立。
- 偏好仅保存在当前浏览器localStorage，刷新保留，其他浏览器独立；损坏/未知值回退默认。设置面板也按需加载。

键盘主流程：

| 操作 | 行为 |
| --- | --- |
| Tab / Shift+Tab | 依次导航控件，弹窗内循环；关闭时返回入口或下一可用游戏控件 |
| Enter / Space | 激活当前原生按钮，输入框仍可正常输入空格 |
| 跳到主要内容 | 跳过头部导航，将焦点移到主区域 |
| 主区域空格 | 在合法回合掷骰；重复按键不多掷 |
| 主区域1～4 | 按飞机编号选择合法落点预览，不立即移动；焦点进入预览 |
| 预览区域Enter | 确认当前飞机；仍经Go校验和去重 |
| Esc | 取消预览/关闭弹窗，未确认不会移动或结束游戏 |
| 主区域P | 打开道具口袋 |

快捷键不抢占输入框、下拉框、按钮、链接、原生控件或已打开弹窗。修复骰子关闭后快速选子会被旧焦点恢复抢走的竞争情况；主页面跳转主动定位main。3D棋盘有可聚焦文字操作，2D有编号和标签；焦点轮廓可见。手机关键设置/回合/道具/预览/弹窗按钮至少44px，头部允许换行，避免裁切；不宣称全部SVG图元均有44px触控面积，飞机也可通过名字按钮选择。

## 实际Chrome验收

`test:accessibility:browser` 使用原生Chrome，macOS Metal，未设置绕过自动播放参数；关闭麦克风和主动播报。

- 仅键盘完成设置、创建、带空格昵称、三步指南、打开/退出道具、起飞卡、实际随机投掷、预览/取消/确认起飞、暂停/继续/结束与取消结束。
- 键盘游玩时，真实点数对应静态骰子，等待超过普通弹窗自动关闭时间后仍可确认；点击游玩静态展示后自动继续。按住/重复空格只投一次，飞机只起飞一次，输入昵称和弹窗内操作不误触棋步。
- 正式API和服务端随机骰子推进另一个自然完成的棋局，没有位置/点数注入；随后仅键盘查看结算、同配置再玩，统计清零、新游戏ID、轻量偏好保留。完整自然局的中间棋步通过正式命令推进，不声称每一步都用键盘。
- 刷新偏好、独立浏览器、系统减少动画实时变更；自动/平面切换，权威State逐字段不变，旧画布移除并释放WebGL上下文。
- 首次进入轻量棋盘无WebGL、无立体模块请求；有意中止立体模块下载后，直接切换轻量恢复原棋局，不重新加载页面。
- 390×844与844×390无页面横向溢出，设置目标至少44px且不被头部裁切；弹窗可以滚动查看全部说明/完成按钮。
- 页面错误0，麦克风请求0。截图为桌面Chrome视口，不等于新增实体低性能手机或读屏器验收。

公网复跑同样通过，运行二进制与发布文件、6个静态资源一致，语音仍已配置，数据库与凭据权限600、schema3。公网首次进入轻量棋盘的ResourceTiming：入口encodedBodySize127524字节（解码398323），平面入口270，共享棋盘4495（解码11117）；立体Board模块未请求。测试先在首页保存偏好再刷新，入口可能来自缓存；这些是该构建的响应体字节，不是总网络流量、帧率、续航或首屏耗时结论。

另有3个组件/偏好测试：损坏设置默认、真实双骰静态点数、减少动画胜利提示无粒子；16语音生命周期、6展示、4播报/音效和构建通过。既有新手安静引导、跳过/重看、幸运骰、结束失败/成功、预览/切换/取消/确认及跳跃/飞行/撞机/终点/护盾/2D降级回归通过。

3D资源专项：30次实际投掷与棋盘切换，正常过程中1个活动上下文，Buffer378、Texture17、Program5、Framebuffer4保持稳定；故意丢失/自动恢复/手动恢复、WebGL不可用仍可降级游玩。该脚本现也不依赖绕过自动播放参数，仅用于图形验证。

## 减少动画与真实语音兼容

本地应用通过原生Chrome、Tingting合成WAV麦克风、真实worklet/Go/灵矽验证，未绕过自动播放：先按Tab进入键盘模式，再改说话，识别到用户转写后切回语音自动继续。查询→起飞卡→真实随机1点→小熊号起飞→查询→否定→真实断开重连通过，版本1→2→3→4后保持；骰子弹窗自动结束，棋盘展示也到版本4。只问才答模式主动host_cue为0，页面错误0。该项是合成音频与真实平台联调，不是新增真人或长监听验收。

对应脚本在既有真实语音复跑命令基础上加 `QA_REDUCED_MOTION=1 QA_KEYBOARD_BEFORE_SPEECH=1`；音源准备与凭据本机配置见 [语音验收](QA-VOICE.md)。公网点击/键盘脚本另行验证减少动画投掷自动继续与键盘等待确认。

## 边界与上线

这轮不改变Go规则、语音协议、身份/存档格式；不把减少下载解释为真实低端机FPS或续航保证，也不是完整WCAG/VoiceOver认证。#3 的切网、后台挂起、长时间真实监听与比赛交付仍开放；此前用户确认的亲子与实体手机验收保持完成，不重复索要。

上线前在线备份，运行二进制与发布文件、全部静态资源逐一核对；保留schema3数据库和语音配置。应用提交与截图来源分开记录，真实域名、SSH凭据、Cookie或API Key均不写入仓库。

LISTEN_ADDR=127.0.0.1:8080 SAVE_PATH=/tmp/flytogether-access.db /tmp/flytogether-qa-server
