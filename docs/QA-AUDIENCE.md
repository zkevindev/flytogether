2026-10-24，跟踪 #39～#44。功能基础 `1143597`，会话和恢复修正 `3c88202`。本页区分软件验证、真实平台音频和实体设备反馈。

## 交付行为

- 联网房主可开关观赛、复制或更新独立观赛链接，禁止或允许观众发言。观赛凭证与入座邀请分离。更新链接仅阻止旧链接新加入；关闭观赛撤销已有身份和助手。容量与加入频率可配置。
- 昵称加入不占比赛席位、不参与准备。刷新恢复身份，多标签页算一人，退出只移除自己。原选手打开观赛链接保留席位。
- 观赛快照去除入座邀请、家庭档案标识、操作授权和选手对讲状态。HTTP、游戏订阅、语音及工具分别检查身份；伪造选手 ID 不会升级权限。
- 独立页面展示回合、真实点数、飞机与道具、选手、观众数及最近棋步。等待、暂停、获胜和主动结束均有说明。骰子先于后续飞行；新加入和重连只绑定当前局面。动画落后较多时直接跟上最新棋盘，避免积压旧骰子。
- 观众默认不申请麦克风。点击“开始提问”后使用自己的 `/ws/audience-voice`，拥有独立上下文、音频与打断状态，不占选手租约。常见回合、进度和最近棋步问题由 Go 已确认事实生成，再由灵矽朗读；规则等开放问题先刷新只读工具。观众操作请求只会被拒绝。
- 撤权、退出、手动结束、换局、删除或过期房间会结束该观众的助手；旧连接的迟到工具不得读取新局。比赛暂停仍可提问。正常获胜可了解结果；同房间再玩清空互动与旧助手上下文。
- 表情及最多 40 字短消息与语音私聊分开；可给选手加油、隐藏消息、单独屏蔽来源。服务端去重、限制发送频率并最多保留 40 条；同局持久化，随再玩、删除或房间保留期清理。消息不自动 TTS，不改变棋局或进入助手工具上下文。
- 观众语音有独立并发、时长和日额度；不足时仍能安静观看。后台语音筛选包含 `spectator` 来源，并按独立 session/input 归属对局，遵循文本开关和保留期，不保存原始录音。

## 复跑

先启动已构建的 Go 服务，通过本机环境变量指定目标地址；不要把真实地址、密钥或 Cookie 写进仓库。

```sh
QA_BASE_URL=http://127.0.0.1:8080 \
QA_OUTPUT_DIR=/tmp/flytogether-audience \
npm --prefix web run test:audience:browser

python3 scripts/voice_fixture.py --scenario audience-host --output-dir /tmp/flytogether-audience-audio/host
python3 scripts/voice_fixture.py --scenario audience-a --output-dir /tmp/flytogether-audience-audio/a
python3 scripts/voice_fixture.py --scenario audience-b --output-dir /tmp/flytogether-audience-audio/b
QA_BASE_URL=http://127.0.0.1:8080 \
QA_AUDIENCE_AUDIO_DIR=/tmp/flytogether-audience-audio \
QA_OUTPUT_DIR=/tmp/flytogether-audience-voice \
npm --prefix web run test:audience:voice
```

语音生成需要 macOS `say` 和 FFmpeg，其他平台可提供等价 16kHz 单声道 WAV。重启脚本另要求 `QA_RESTART_SCRIPT` 和可选 `QA_RESTART_PYTHON`，仅用于明确获准重启的目标服务，不会自动选择其他进程。
