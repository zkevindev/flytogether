# 一起飞 · 产品化路线

更新：2026-10-24。跟踪：[产品化 1.0 / #17](https://github.com/zkevindev/flytogether/issues/17)、[实机与比赛交付 / #3](https://github.com/zkevindev/flytogether/issues/3)。

本文是下一阶段计划，未勾选事项尚未交付。当前已实现能力见 [README](../README.md)，实际变更与证据见 [进展记录](PROGRESS.md)。

## 1.0 要完成什么

先把“家长和孩子在同一块屏幕上玩的语音飞行棋”做完整：首次打开能理解，创建后能顺利玩完，中途退出能继续，结束后能看到结果并再来一局。点击操作始终可用，语音让陪玩更自然。

当前已经有创建、独立棋盘、五种道具、AI、直接语音、主动回合播报、撒花和音效。用户已选择首先实施 [新手引导与落点预览 / #18](https://github.com/zkevindev/flytogether/issues/18)，该切片的实际完成情况以 Issue 和 README 为准。#21 补齐结算与同配置再玩，#22 增加免注册邀请联机。主要缺口仍是持久化、独立声音控制与家庭真实设备验收。

## 当前产品边界

| 维度 | 当前事实 | 1.0 目标 |
| --- | --- | --- |
| 房间 | 同屏，或免注册邀请联机；Cookie 绑定自己的席位 | 同屏体验完整，入口与状态清楚 |
| 保存 | 内存房间；刷新可续，服务重启失效；无监听且空闲超过约 4 小时会清理 | 已确认操作落盘，重启后可恢复为暂停 |
| 教学 | 三步新手指南、落点预览与确认、规则弹窗、语音问答 | 可跳过的首次引导与分阶段提示 |
| 结束 | 动画后结算、真实统计、同配置再玩；手动结束回首页 | 有真实结果、统计、再玩和返回的结算流程 |
| 语音 | 直接对话、打断、独立回合播报、有限缓冲 | 声音控制清楚，故障可恢复，成本有边界 |
| 验收 | 自动与受控故障回归、真实平台、有限真人确认 | 补齐真实手机、家庭完整局与长时间场景 |

## P0：完整性与可靠性

### 1. 存档与续玩

用户收益：吃饭后还能继续，部署更新不会丢掉刚才的棋局。

- [ ] Go 单实例先用 SQLite 保存房间、玩家、棋局、道具、状态版本与必要的命令去重结果。
- [ ] 动作落盘成功后才向客户端确认；失败时不展示“已经走完”。
- [ ] 重启恢复为暂停，保留骰子和选子阶段；不恢复旧语音响应、动作授权和 AI 定时任务。
- [ ] 首页显示可继续的对局与最近保存时间，提供明确的放弃/删除入口。
- [ ] 明确保存期限、浏览器会话过期行为；数据库备份与恢复有复跑步骤。

验收：在掷骰后、选子后、使用道具后分别重启，棋局和库存一致；重复提交同一个操作不多掷一次、不多扣库存；损坏或旧版本存档不会造成空白页。初期不要求账号登录或跨设备恢复。

### 2. 新手引导与操作预览——当前切片 #18

用户收益：第一次玩的孩子知道现在该做什么，家长不用边玩边翻规则。

- [x] 首次进入简短说明“谁先掷骰、六点起飞、起飞卡怎么用”，能跳过和重新查看。
- [x] 回合提示区分“轮到你掷骰”和“请选择一架飞机”，道具不可用时给具体原因。
- [x] 选子前预览落点、跳格、撞机或终点，预览取自 Go 的合法走法。
- [x] 语音不确定时追问，查询和建议保持只读；推荐不会替用户消耗道具。

已完成实际浏览器回归：引导跳过/完成/重看，预览不写入、确认一次、特殊效果一致、手机视口与 2D 降级。没有开发者协助的新用户与真实亲子试玩仍由 #3 验收，不以脚本代替。

### 3. 结算与再玩

用户收益：一局有正式的结束，也有自然的下一局入口。

- [x] 结算展示冠军、已抵达飞机与本局实际统计；没有可靠记录的数据不展示。
- [x] 区分正常获胜、主动结束和中途离开；中途结束不生成虚假冠军。
- [x] “同配置再来一局”“换玩法”“返回首页”三条路径明确。
- [x] 再开局库存、动画、播报、计时和版本全部独立，旧响应不能污染新局。

验收：快速局先到一架、完整局全部抵达均进入正确结算；刷新不会重复加战绩；结束后不再自动掷骰或继续采集麦克风。

### 4. 声音与故障恢复

用户收益：不想开麦也能听回合播报；断网或音频暂停后知道怎么继续。

- [ ] 分别控制对讲麦克风、回合播报与游戏音效，保留偏好并提供总静音。
- [ ] 麦克风拒绝、声音锁定、音频上下文暂停、上游不可用有简短明确的恢复入口。
- [x] 游戏连接断开时显示状态，重连先读取权威快照，再允许提交新操作。
- [ ] 只安全重试：写请求沿用原 command ID，不能重连后再随机掷一次。
- [ ] 多房间语音并发、合成超时、费用和限流设置边界；失败时继续点击玩法。

验收：拒绝权限、断网恢复、后台回来和长语音均有可用出口；无重复动作、无人声持续采集提示缺失或无限重连。已有播放队列修复的证据见 [语音验收](QA-VOICE.md)。

### 5. 家庭与设备验收

- [ ] 覆盖真实亲子完整局，快速/完整模式各有记录；匿名记录问题与是否修复。
- [ ] 覆盖 2～4 席、AI 三档、五道具、胜负与重开。
- [ ] 至少检查桌面 Chrome、真实 Android Chrome 和 iOS Safari；不支持的能力明确提示。
- [ ] 记录切网、后台、噪声、回声、说话距离和长时间游玩的表现。
- [ ] 建立演示备份、发布检查和回滚流程，明确公开发布所需许可证及素材来源。

验收归属：#3。自动化、合成音频和有限真人样本分开记录；页面缩到手机宽度不等于真实手机验收。

## P1：让家庭更愿意再玩

| 方向 | 可交付切片 | 验收重点 |
| --- | --- | --- |
| 灵矽陪玩 | #20 已交付版本绑定的建议预览、连续比较与明确确认；后续教学、鼓励和解说偏好 | 频率可调、可跳过、不抢连续对话、不编造操作结果 |
| 规则与节奏 | 亲子/经典预设，说明起飞与胜利条件；根据试玩调整道具库存 | 点击、AI、语音共用 Go 规则；规则在一局内固定 |
| 可选特殊玩法 | 再根据试玩选择天气、补给或合作目标等机制 | 清楚显示规则变化，有实际选择，不只是随机惩罚与动画 |
| 家庭档案 | 同一浏览器记昵称、头像和历史战绩 | 建立在存档之上，可删除，不保存原始语音 |
| 手机与可访问性 | 大触控区域、编号与颜色并用、键盘与减少动画 | 平板横竖屏可用，低性能设备可走 2D 降级 |
| 首次加载 | 首页与 Three.js 棋盘按需加载，减少无关下载 | 对比真实首屏时间与下载大小，不只报构建文件大小 |

### 已选择的陪玩切片 #20

语音教练与点击入口共用 Go 的当前合法走法，推荐、换选、安全比较和回看只更新预览；明确确认才执行一次真实移动。版本变化与暂停/结束/新局/语音断开清除建议；不同提案 ID 防止同版本下确认错飞机。合作救援、人格化对手和局内任务尚未实现。

## P2：扩展产品形态

用户选择的 #22 已实现独立邀请凭证、席位 Cookie、房主权限、准备/在线状态、原浏览器重连和当前玩家操作授权。首版不含账号、房主转让、自动托管和服务重启恢复；真实手机与多人声学环境仍由 #3 验收。其他可选扩展有主题棋盘、挑战玩法、安装到桌面和更多主持风格。

## 实施顺序与发布门槛

当前优先顺序：**新手引导＋落点预览 → 结算再玩 → 亲子规则与灵矽陪玩 → 存档续玩与异常恢复 → 家庭验收**。玩法切片与可靠性任务都属于 1.0 门槛；完成引导不表示已交付结算、存档或其他计划。每次选择一个可验收切片，直接提交 main，Issue 回链代码和证据；联网扩展以独立 Issue #22 跟踪，不替代存档和家庭验收。

同屏 1.0 发布前，P0 都应有实际验证记录；存在未覆盖设备时明确说明范围，不能只把已有功能列表改名为“完整产品”。每个可见界面变更同步更新 [截图说明](SCREENSHOTS.md)；README 只写已经可用的能力，计划保留在本文。
