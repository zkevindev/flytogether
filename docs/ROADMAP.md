# 一起飞 · 产品化路线

更新：2026-10-24。跟踪：[产品化 1.0 / #17](https://github.com/zkevindev/flytogether/issues/17)、[实机与比赛交付 / #3](https://github.com/zkevindev/flytogether/issues/3)。

本文是下一阶段计划，未勾选事项尚未交付。当前已实现能力见 [README](../README.md)，实际变更与证据见 [进展记录](PROGRESS.md)。

## 1.0 要完成什么

把“家长和孩子可同屏、也可各用一台设备玩的语音飞行棋”做完整：首次打开能理解，创建后能顺利玩完，中途退出能继续，结束后能看到结果并再来一局。点击操作始终可用，语音让陪玩更自然。

当前已经有创建、独立棋盘、八种道具与特效、AI、直接语音、主动回合播报、撒花和音效。早期选择的 [新手引导与落点预览 / #18](https://github.com/zkevindev/flytogether/issues/18) 已完成，#35房主交接、#36八种道具与反馈已部署。#21 补齐结算与同配置再玩，#22 增加免注册邀请联机。本轮 #24/#25 已补齐持久化、独立声音控制与语音资源限制；真实亲子与实体手机验收也已由用户确认完成；更多专项稳定性与比赛交付资料由 #3 跟踪。

## 下一阶段优先级

观赛首版已在本地实现：观众不占席位，独立观赛页同步棋局，每位观众可连接自己的只读灵犀，表情和短文字走独立频道。公网部署、真实灵犀双端连麦式验收和实体手机不在本次本地记录内。其余切片以“能顺利玩完、愿意再玩、问题能追踪”为后续验收目标。已有功能继续维护，覆盖率专项#34保留后续迭代，不作为本阶段交付阻塞。

观赛首版已经按这个边界实现：每位观众使用独立 Realtime 链路，任何回合可提问；只读最新棋局，回复只在该观众页面播放。表情和短文字走独立消息，不自动播报，也不变成比赛指令。房主可关闭观赛或禁止观众发言。首版没有多人语音连麦或公开房间大厅。详见[#39](https://github.com/zkevindev/flytogether/issues/39)和[观赛验收](QA-AUDIENCE.md)。

这里将玩家反馈与后台功能分开：现有/admin是只读查询工具，不等于已有工单处理或玩家反馈入口。真人席位托管已由#38独立交付，与房主交接分开管理。

浏览器进入后台可能暂停动画并限制部分计时，见[MDN Page Visibility](https://developer.mozilla.org/en-US/docs/Web/API/Page_Visibility_API)。因此托管在Go端调度，页面隐藏本身不代表玩家离线，更不代表同意AI代玩。

原生Realtime MCP已完成能力核对，生产游戏仍使用现有Go授权工具链。游戏MCP化可在复用/扩展工具有明确收益时独立实施，保留席位/轮次权限、幂等和结果确认；不将协议迁移算作新增玩家玩法。安装到桌面、更多主题与道具在上述切片之后按反馈排期。

这一节是产品计划，不代表上述功能已上线。已有亲子与实体手机完成确认保持不变，新的专项测试单独记录。

## 当前产品边界

| 维度 | 当前事实 | 1.0 目标 |
| --- | --- | --- |
| 房间 | 同屏，或免注册邀请联机；Cookie 绑定自己的席位 | 同屏体验完整，入口与状态清楚 |
| 保存 | SQLite 保存；重启暂停、原浏览器回座；默认闲置 7 天清理 | 已确认操作落盘，重启后可恢复为暂停 |
| 教学 | 三步新手指南、落点预览与确认、规则弹窗、语音问答 | 可跳过的首次引导与分阶段提示 |
| 结束 | 动画后结算、真实统计、同配置再玩；手动结束回首页 | 有真实结果、统计、再玩和返回的结算流程 |
| 语音 | 直接对话、打断、独立回合播报、有限缓冲 | 声音控制清楚，故障可恢复，成本有边界 |
| 验收 | 自动与受控故障回归、真实平台，用户确认亲子与实体手机完成 | 补齐真实手机与家庭已由用户确认，长时间专项继续记录 |

## P0：完整性与可靠性

### 1. 存档与续玩

用户收益：吃饭后还能继续，部署更新不会丢掉刚才的棋局。

- [x] Go 单实例先用 SQLite 保存房间、玩家、棋局、道具、状态版本与必要的命令去重结果。
- [x] 动作落盘成功后才向客户端确认；失败时不展示“已经走完”。
- [x] 重启恢复为暂停，保留骰子和选子阶段；不恢复旧语音响应、动作授权和 AI 定时任务。
- [x] 首页显示可继续的对局与最近保存时间，提供明确的放弃/删除入口。
- [x] 明确保存期限、浏览器会话过期行为；数据库备份与恢复有复跑步骤。

验收：在掷骰后、选子后、使用道具后分别重启，棋局和库存一致；重复提交同一个操作不多掷一次、不多扣库存；损坏或旧版本存档不会造成空白页。初期不要求账号登录或跨设备恢复。

### 2. 新手引导与操作预览——当前切片 #18

用户收益：第一次玩的孩子知道现在该做什么，家长不用边玩边翻规则。

- [x] 首次进入简短说明“谁先掷骰、六点起飞、起飞卡怎么用”，能跳过和重新查看。
- [x] 回合提示区分“轮到你掷骰”和“请选择一架飞机”，道具不可用时给具体原因。
- [x] 选子前预览落点、跳格、撞机或终点，预览取自 Go 的合法走法。
- [x] 语音不确定时追问，查询和建议保持只读；推荐不会替用户消耗道具。

已完成实际浏览器回归：引导跳过/完成/重看，预览不写入、确认一次、特殊效果一致、手机视口与 2D 降级。用户已确认真实亲子与实体手机验收完成；以上自动化范围仍单独记录，不替代用户反馈。

### 3. 结算与再玩

用户收益：一局有正式的结束，也有自然的下一局入口。

- [x] 结算展示冠军、已抵达飞机与本局实际统计；没有可靠记录的数据不展示。
- [x] 区分正常获胜、主动结束和中途离开；中途结束不生成虚假冠军。
- [x] “同配置再来一局”“换玩法”“返回首页”三条路径明确。
- [x] 再开局库存、动画、播报、计时和版本全部独立，旧响应不能污染新局。

验收：快速局先到一架、完整局全部抵达均进入正确结算；刷新不会重复加战绩；结束后不再自动掷骰或继续采集麦克风。

### 4. 声音与故障恢复

用户收益：不想开麦也能听回合播报；断网或音频暂停后知道怎么继续。

- [x] 分别控制对讲麦克风、回合播报与游戏音效，保留偏好并提供总静音。
- [x] 麦克风拒绝、声音锁定、音频上下文暂停、上游不可用有简短明确的恢复入口。
- [x] 游戏连接断开时显示状态，重连先读取权威快照，再允许提交新操作。
- [x] 只安全重试：写请求沿用原 command ID，不能重连后再随机掷一次。
- [x] 多房间语音并发、合成超时、费用和限流设置边界；失败时继续点击玩法。

验收：拒绝权限、断网恢复、后台回来和长语音均有可用出口；无重复动作、无人声持续采集提示缺失或无限重连。已有播放队列修复的证据见 [语音验收](QA-VOICE.md)。

### 5. 家庭与设备验收

- [x] 真实亲子完整对局验收：2026-10-24 用户确认完成。
- [ ] 汇总并补齐 2～4 席、AI 三档、八道具、胜负与重开的统一回归矩阵；现有分项验收见QA-NETWORK、QA-PROPS，尚不把分项通过当成所有组合已覆盖。
- [x] 实体手机验收：2026-10-24 用户确认完成；不推断具体设备型号或浏览器版本。
- [ ] 记录切网、后台、噪声、回声、说话距离和长时间游玩的表现。
- [ ] 建立演示备份、发布检查和回滚流程，明确公开发布所需许可证及素材来源。

验收归属：#3。自动化、合成音频和有限真人样本分开记录；页面缩到手机宽度不等于真实手机验收。

### 已选择的陪玩切片 #20

语音教练与点击入口共用 Go 的当前合法走法，推荐、换选、安全比较和回看只更新预览；明确确认才执行一次真实移动。版本变化与暂停/结束/新局/语音断开清除建议；不同提案 ID 防止同版本下确认错飞机。合作救援、人格化对手和局内任务尚未实现。
